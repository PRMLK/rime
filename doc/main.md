# Frontend Conventions

- Use the installed `shadcn` skill for all UI work.
- Prefer installed shadcn/ui components and their documented composition patterns over custom control markup.
- Use semantic theme tokens and component variants; do not introduce raw palette colors for component styling.
- Check the shadcn registry and component documentation before adding a new UI component.

# Git Commit Conventions

- Review the working tree and run relevant validation before committing.
- Use the configured Git user identity as the sole commit author.
- Do not add Codex or any automated assistant as a co-author or collaborator.
- Write a concise commit subject and a body that describes the user-facing or technical scope of the change.
